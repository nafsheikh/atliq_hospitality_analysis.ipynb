# AtliQ Hospitality Data Analysis

## About This Project

This is a Python data analysis project based on AtliQ Hotels data.

I worked on this project to practice how a data analyst can take raw data, clean it, analyze it and find useful insights from it.

The data contains information about hotel bookings, properties, room categories, occupancy, revenue, booking platforms and customer ratings.

My main focus was to understand how different properties and cities are performing in terms of occupancy and revenue.

---

## Tools I Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

---

## Dataset

I worked with multiple CSV files in this project:

- `fact_bookings.csv` - Contains booking-level information
- `fact_aggregated_bookings.csv` - Contains successful bookings and room capacity
- `dim_hotels.csv` - Contains property, city and hotel category information
- `dim_rooms.csv` - Contains room category information
- `dim_date.csv` - Contains date-related information
- `new_data_august.csv` - Additional booking data for August

All datasets are available inside the `datasets` folder.

---

## What I Did

I started by understanding the datasets and checking the important columns.

After that, I performed data cleaning where I:

- Checked missing values
- Found and removed invalid guest records
- Checked revenue outliers using mean and standard deviation
- Checked high revenue values for the Presidential room category separately
- Checked the data before starting the main analysis

Then I transformed the data by calculating occupancy percentage and merging different tables whenever required.

After cleaning and transforming the data, I started answering different business questions using Pandas and created charts using Matplotlib.

---

## Analysis I Performed

Some of the questions I worked on were:

1. What is the average occupancy rate for each room category?
2. What is the average occupancy rate by city?
3. Is occupancy higher on weekdays or weekends?
4. What is the occupancy rate by city in June?
5. How does adding new August data affect the available booking data?
6. How much revenue is generated by each city?
7. How does revenue change month by month?
8. How much revenue is generated by each property?
9. What is the revenue contribution of each booking platform?

---

## Some Insights From My Analysis

### Property Revenue

Atliq Exotica generated the highest revenue at around **₹32.5M**, followed by Atliq Palace at around **₹31M**.

Atliq Seasons generated the lowest revenue at around **₹6.5M**, which shows a large revenue gap compared with the other properties.

### Booking Platform Revenue

The **"Others"** booking platform category contributed the highest share of revenue at **40.9%**.

MakeYourTrip was the second-largest contributor with **19.9%**, followed by LogTrip with **11.0%**.

Direct Offline had the lowest revenue contribution at **5.1%**.

### Occupancy Analysis

I also compared occupancy across room categories, cities and weekdays/weekends. This helped me understand that hotel performance can be different depending on the location, room type and day type.

### Monthly Revenue

I analyzed revenue month by month to understand how revenue changes over time and to identify stronger and weaker periods.
